# NANOGRAM Launcher

Windows向けの高速デスクトップアプリランチャー。Tauri v2 + React + Rust で構築。

---

## 概要

NANOGRAM Launcher は、キーボード操作を中心とした軽量・高速なアプリケーションランチャーです。Ctrl キーのダブルタップで即座に起動し、インクリメンタル検索でアプリを素早く見つけて起動できます。

フレームレスの透過ウィンドウでデスクトップに自然に溶け込み、フォーカスを失うと自動的に非表示になるため、作業の邪魔になりません。

## 特徴

### 高速検索

- インクリメンタル検索（入力と同時にリアルタイムで結果表示）
- アプリ名の完全一致・前方一致・部分一致・部分列マッチに対応
- タグによるカスタム検索
- 使用頻度と最終使用日時を加味したスマートランキング

### 柔軟なアプリ管理

- フォルダスキャンによる自動登録（`.exe`, `.lnk` 対応）
- Windows スタートメニューからの一括インポート
- ドラッグ&ドロップでファイル・フォルダを直接登録
- アプリごとのタグ付け・リネーム・除外
- シェルコマンドの登録・実行（管理者権限・ウィンドウ保持オプション付き）

### 固定エリア（ピン留め）

- よく使うアプリをグリッドにピン留め
- マウスドラッグで自由に並び替え
- 列数（5〜15）・行数（1〜5）を設定でカスタマイズ

### セクション表示

- **最近使った** — 直近に起動したアプリ
- **よく使う** — 起動回数が多いアプリ
- **固定** — ピン留めしたアプリのグリッド
- 各セクションの表示/非表示・表示順序を設定で変更可能

### 操作性

- **Ctrl×2（ダブルタップ）** で瞬時に起動/非表示
- カスタムホットキー対応（Alt, Shift, Ctrl+Space など）
- **Ctrl+↑/↓** で検索履歴をターミナルライクに遡行（最大100件）
- **↑/↓** で検索候補を選択、**Enter** で起動
- **Esc** でクリア/非表示
- フォーカス喪失で自動非表示

### マルチモニター対応

- カーソルのあるモニターの中央に表示
- DPIスケーリングの異なるモニター間でも正確に配置
- 設定のグリッドサイズに応じてウィンドウサイズを自動計算

### 重複起動防止

- 同名のプロセスが既に実行中の場合、新規起動せず既存ウィンドウを前面に復帰
- 異なるパスの同一アプリ（ショートカットと本体など）にも対応

### 設定画面

- 別ウィンドウで表示（ランチャーと同時に操作可能）
- 設定変更がランチャーにリアルタイム反映
- テーマ切替（ライト/ダーク/システム連動）
- 自動起動設定

## インストール

### ビルド済みバイナリ

`nanogram desktop LauncheR.exe` を任意のフォルダに配置して実行してください。初回起動時に `settings.json` が自動生成されます。

### ソースからビルド

```bash
# 前提条件: Node.js, Rust toolchain, Tauri CLI

# 依存パッケージのインストール
npm install

# 開発モード
npx tauri dev

# リリースビルド
CARGO_TARGET_DIR="C:/tmp/launcher-target" npx tauri build
```

## 使い方

1. `nanogram desktop LauncheR.exe` を起動（システムトレイに常駐）
2. **Ctrl キーを素早く2回押す** とランチャーが表示
3. アプリ名を入力して検索、**Enter** で起動
4. 歯車アイコンまたは **Ctrl+,** で設定画面を開く

### アプリの登録方法

- **フォルダスキャン**: 設定 → スキャンフォルダ → フォルダを追加
- **スタートメニュー**: スキャンフォルダ画面からワンクリックで一括登録
- **ドラッグ&ドロップ**: ランチャー画面に `.exe` / `.lnk` / フォルダをドロップ

### ピン留め

- 検索結果やセクション上のアプリを右クリック → 「固定エリアに追加」
- 固定エリア内でドラッグして並び替え
- 右クリック → 「固定を解除」で解除

### 検索履歴

- **Ctrl+↑**: 過去の検索クエリを遡る
- **Ctrl+↓**: 新しい方に戻る
- アプリ起動時に自動保存（最大100件）

## 設定項目

| 項目 | 説明 | デフォルト |
|------|------|-----------|
| ホットキー | 起動キー（Ctrl/Alt/Shift のダブルタップ、またはキーコンビネーション） | Ctrl×2 |
| テーマ | ライト / ダーク / システム連動 | システム |
| 自動起動 | OS起動時に自動起動 | OFF |
| 検索結果数 | 最大表示件数（4〜20） | 8 |
| 最近使った表示数 | 0〜20 | 8 |
| よく使う表示数 | 0〜20 | 8 |
| 固定エリア列数 | 5〜15 | 9 |
| 固定エリア行数 | 1〜5 | 2 |
| セクション設定 | 表示/非表示・表示順序の変更 | 全セクション表示 |

## 検索ランキングアルゴリズム

```
スコア = 名前マッチボーナス + タグマッチ(40) + 使用頻度 + 新しさ

名前マッチ:
  完全一致  → 100点
  前方一致  → 80点
  部分一致  → 50点
  部分列    → 30点

使用頻度: ln(起動回数 + 1) × 10
新しさ:   20 × exp(-経過時間(h) / 168)
```

## 開発履歴

### v1.0.1（2026年4月）

- **テーマ切り替えの即時反映**: ランチャーウィンドウがテーマ変更を即座に反映するよう修正
- **ライトモードの角丸問題を修正**: Mica/Acrylic エフェクトをテーマに合わせて再適用するよう変更。起動時も `settings.json` のテーマを読んで正しいダーク/ライトモードで適用
- **ライトモードの明るさ改善**: 背景の不透明度を引き上げてより明るい表示に
- **固定エリア列数変更後の再固定バグを修正**: 列数を減らして固定解除されたアイテムが「固定登録済み」と誤判定され再登録できない問題を解消。設定変更をランチャーに即時反映するよう修正
- **設定の即時保存**: 列数・行数変更時にウィンドウを閉じても設定が失われないよう即座にディスク保存
- **デバッグログ出力の削除**: 起動ごとに `single_instance_debug.log` を生成していた処理を削除
